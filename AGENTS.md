# Resid Language

Resid = eager compile-time language: compiling mean maximal authorized reduction of first-class knowledge. This repo hold language spec plus in-progress Rust/Cargo build.

- **Source of truth**: `resid_specification.txt` — full language spec (now **v3.0 — Production Ready**). All design question must get answer from it, no exception.
- **Implementation**: Cargo workspace. Members under `crates/` (lexer, parser, ir, type, codegen, builtin, build, residc) and `tools/` (fmt, notes, cache, graph, why).
- **Status**: lexer 13, parser 88, resid-ir 41, resid-type 158, resid-codegen 118, residc 23 — **441 tests pass**. Operator precedence per spec §27 (multiplicative > additive > … > logical AND/OR; binary left-associative, ranges right-associative). `resid-ir` build spec-§6 primitive numeric types plus mixed-width widening. `resid-type` cover literal inference, widening, signed/unsigned mixing rejection, bitwise/float errors, cast, if, RT, built-in extern signatures, `Str + Str`, `check_program`, and (Step 1) lists, structs, options, pattern matching, numeric overload resolution (`IntToString`/`UIntToString`/`FloatToString`/`BoolToString`/`ToString`), numeric widening at call sites, string introspection built-ins (`str_len`/`str_char_at`/`str_from_code`/`str_slice`), and wide ToString built-ins (`Int128ToString`/`UInt128ToString`/`Int256ToString`/`UInt256ToString`/`Int512ToString`/`UInt512ToString`). `resid-type` also reject shadowing everywhere (spec §7) via `Env::try_insert` — same-block, nested-block, for-in loop vars, pattern binds, and duplicate params all error; sibling blocks still bind freely. `resid-codegen` spit out verified LLVM IR: functions, arithmetic, casts, calls, bool, string literals/f-strings/raw strings (global constants), string-concat folding, extern built-ins (`print`/`println`), boxed composite values (`List`/`Struct`/`Option` via `resid_box_*` runtime calls, `match` with tag checks + phi joins), Bool↔i8 C ABI widening (user functions declare Bool params as i8 and narrow to i1 on entry), runtime value formatting helpers, `value?`/`value else { … }` unwrap (payload from box slot 0), nested-`if` phi joins, early `return` in if/else branches (emitted as a real `ret`, enabling recursion), and wide integer support — `Int(128)`/`UInt(128)` (i128 lowering, literals built from full decimal value via `const_int_from_string` with magnitude-derived width when no target, `Int128ToString`/`UInt128ToString` runtime decimal printers) plus `Int(256)`/`Int(512)` arithmetic via LLVM arbitrary-width integers and `Int256ToString`/`UInt256ToString`/`Int512ToString`/`UInt512ToString` limb-decomposed C-ABI helpers. `resid-parser` handles C-style casts `(Type)expr`, named call args, raw/byte strings, `_ = expr` discard, struct destructuring, and bare block statements; the type checker (not the parser) rejects undefined variables. Functions may be called before their definition (all declared before lowering), so forward references and mutual recursion work. **M4 done**: `examples/lexer.res` (bootstrap lexer written in Resid) reads a `.resid` file via `filesystem.read_all(RESID_LEX_SRC)` and prints the token stream — C-style comments (`//`, `/* */`), string/raw/byte/f-string/char literals, dec/hex/bin/oct ints, floats, ident/keyword, operators. Proven by e2e test `bootstrap_lexer_tokenizes_source`. **M5 done**: `examples/parser.res` (bootstrap parser written in Resid) reads a `.resid` file via `filesystem.read_all(RESID_PARSER_SRC)`, recursively descends with position threaded through a `{ pos, ast }` struct (immutable bindings), and prints one S-expression AST line per declaration — type-def product/sum, func with params/defaults, bind/discard/return/if-else/while/for-in/expr/block statements, precedence-climbing binary expr (spec §30), unary, calls, field/index/slice, list/struct literals, match, ranges, f-strings/raw/bytes/chars, provider calls. Proves itself by parsing `examples/lexer.res` cleanly to EOF. Proven by e2e test `bootstrap_parser_builds_ast`.
- **Runnable natives**: `residc <f> build [-o out]` build native binary (clang + tiny C runtime `crates/residc/resid_rt.c`), `residc <f> run` build and run it (exit code carry through), `residc <f> emit-ir` print LLVM IR. First bootstrap stage: Resid programs can print to stdout, return exit codes, and format all value types to strings.
- **Branch**: `master` (uncommitted).
