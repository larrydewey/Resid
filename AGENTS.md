# Resid Language

Resid = eager compile-time language: compiling mean maximal authorized reduction of first-class knowledge. This repo hold language spec plus in-progress Rust/Cargo build.

- **Source of truth**: `resid_specification.txt` — full language spec (now **v3.0 — Production Ready**). All design question must get answer from it, no exception.
- **Implementation**: Cargo workspace. Members under `crates/` (lexer, parser, ir, type, codegen, builtin, build, residc) and `tools/` (fmt, notes, cache, graph, why).
- **Status**: 652 tests pass (lexer 17, parser 115, resid-ir 55, resid-type 249, resid-codegen 137, resid-build 47, resid-fmt 5, resid-cache 9, resid-notes 2, resid-why 7, resid-lsp 5, resid-graph 4, residc 0 unit + 94 e2e). Full e2e ≈ 15 min (live-network HTTP/2+TLS and bootstrap-driver runs are slow — not a hang); use `cargo test -p residc --test e2e -- <filter>`. Frontend → LLVM → native binaries all working; **stage-2 self-hosting proven** — `examples/driver.resid` (bootstrap driver regenerated by `tools/merge_driver.py` from `examples/typecheck.resid` + `examples/codegen.resid`) compiles programs identically to the Rust pipeline (e2e: `bootstrap_*` tests). **Graph-driven reduction pipeline**: `residc <f> run|build|emit-ir --graph-reduce` (or `RESID_GRAPH_REDUCE=1`) runs AST→knowledge-graph→§36 β-reduction→retrofit→type-check→codegen with byte-identical output to the plain path (e2e `run_graph_reduce_preserves_behavior`). **Crypto stack in pure Resid** under `lib/`: `crypto.resid` (SHA-256, SHA-512, HMAC-SHA256, PBKDF2-HMAC-SHA256, Base64, constant-time compare, OS-random bytes/hex) and `ed25519.resid` (full RFC 8032 Ed25519 verify + deterministic sign on `Int(256)`/`Int(512)` scalars; RFC test-1/test-3 vectors reproduced byte-for-byte; e2e `run_ed25519_verify_in_resid`, `run_ed25519_sign_in_resid`). Language soundness hardening: list indexing is bounds-checked (`resid_index_abort`), shift counts ≥ bit width yield 0 instead of wrapping. Package system: multi-file imports with import-as namespacing, transitive deps + lockfile, local registry, per-import capability narrowing, Unicode case mapping in stdlib strings. **Map/Set types** (stage-1 done, e2e `run_map_set_types`): immutable persistent `Map(K,V)`/`Set(T)`, literals incl. empty `{}`, indexing `m[k]`→`Option`, `.get/.insert/.remove/.contains/.keys/.values/.len`, Set `.union/.difference/.intersection/.to_list`; FNV-1a over 4-slot buckets (`cap*4` allocation, base `idx*4`); chained postfix calls parse. **Sandboxing (§21)**: `sandbox (caps) { }` blocks parse and flatten; type checker enforces static ceiling on `@requires`; **transitive attenuation enforced** via call-graph meet fixpoint (e2e `run_sandbox_transitive_attenuation`). **Generic numeric behaviors (§6.6)**: `Ord`/`Eq`/`Hash` synthesized for all numeric widths (`Int(w)`, `UInt(w)`, `Float(w)`, `Dec(p)`); `Serialize`/`Allocator` shape-checked; inline comparator trampolines in codegen; e2e `run_generic_numeric_behaviors`. Per-width wrapping/saturating arithmetic (§32) fully implemented. Roadmap (§14 of PROGRESS.md): reduction/cache subsystem, `why` tooling, SpecialCasing, registry transport.
- **Runnable natives**: `residc <f> build [-o out]` build native binary (clang + tiny C runtime `crates/residc/resid_rt.c`), `residc <f> run` build and run it (exit code carry through), `residc <f> emit-ir` print LLVM IR. First bootstrap stage: Resid programs can print to stdout, return exit codes, and format all value types to strings.
- **Branch**: `master`.
