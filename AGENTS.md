# Resid Language

Resid = eager compile-time language: compiling mean maximal authorized reduction of first-class knowledge. This repo hold language spec plus in-progress Rust/Cargo build.

- **Source of truth**: `resid_specification.txt` — full language spec (now **v3.0 — Production Ready**). All design question must get answer from it, no exception.
- **Implementation**: Cargo workspace. Members under `crates/` (lexer, parser, ir, type, codegen, builtin, build, residc) and `tools/` (fmt, notes, cache, graph, why).
- **Status**: 624 tests pass (lexer 17, parser 91, resid-ir 46, resid-type 195, resid-codegen 137, resid-build 12, resid-fmt 5, residc 53 unit + 75 e2e incl. un-ignored wide-int/ECDSA property suites). Frontend → LLVM → native binaries all working; **stage-2 self-hosting proven** — `examples/driver.resid` (bootstrap driver regenerated by `tools/merge_driver.py` from `examples/typecheck.resid` + `examples/codegen.resid`) compiles programs identically to the Rust pipeline (e2e: `bootstrap_*` tests). **Crypto stack in pure Resid** under `lib/`: `crypto.resid` (SHA-256, SHA-512, HMAC-SHA256, PBKDF2-HMAC-SHA256, Base64, constant-time compare, OS-random bytes/hex) and `ed25519.resid` (full RFC 8032 Ed25519 verify + deterministic sign on `Int(256)`/`Int(512)` scalars; RFC test-1/test-3 vectors reproduced byte-for-byte; e2e `run_ed25519_verify_in_resid`, `run_ed25519_sign_in_resid`). Language soundness hardening: list indexing is bounds-checked (`resid_index_abort`), shift counts ≥ bit width yield 0 instead of wrapping. Package system: multi-file imports with import-as namespacing, transitive deps + lockfile, local registry, per-import capability narrowing, Unicode case mapping in stdlib strings. Roadmap (§14 of PROGRESS.md): reduction/cache subsystem, `why` tooling, SpecialCasing, registry transport.
- **Runnable natives**: `residc <f> build [-o out]` build native binary (clang + tiny C runtime `crates/residc/resid_rt.c`), `residc <f> run` build and run it (exit code carry through), `residc <f> emit-ir` print LLVM IR. First bootstrap stage: Resid programs can print to stdout, return exit codes, and format all value types to strings.
- **Branch**: `master`.
