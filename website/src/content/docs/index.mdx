## What remains is what matters

```resid
Int fib(Int n) { return if (n < 2) { n } else { fib(n - 1) + fib(n - 2) }; }

Int main() {
    // Every argument is known, so the compiler computes this while it builds.
    println(f"fib(25) = {fib(25)}");
    return 0;
}
```

```text title="Output"
fib(25) = 75025
```

Resid treats compilation as **reduction of knowledge**. Anything the compiler
can prove, it computes at build time; what stays is the *residual* program,
lowered to native code through LLVM. Every reduction is recorded in a
knowledge graph that the debugger and tools read, so you can always ask
*why* something ran at runtime.

<CardGrid>
	<Card title="Values, not variables" icon="seti:lock">
		Immutable bindings, no null, no shadowing. Maps, lists and strings
		are values, yet updated in place when the compiler proves nobody else
		can see them.
	</Card>
	<Card title="Authority is explicit" icon="approve-check">
		No ambient authority. Every function that touches the filesystem, the
		network or processes says so with `@requires`, checked transitively,
		and libraries can be sandboxed.
	</Card>
	<Card title="Numbers that don't lie" icon="seti:calculator">
		Int(8) to Int(512), Float(16) to Float(128), exact Dec(N). Arithmetic
		is checked at every width; nothing wraps or truncates silently.
	</Card>
	<Card title="Self-hosted, no C" icon="rocket">
		The compiler is written in Resid and compiles itself in about a
		second. The runtime is Resid too: binaries need no C library.
	</Card>
</CardGrid>
